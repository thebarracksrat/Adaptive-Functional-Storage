# Adaptive Functional Storage 0.1.0

Initial public release for Minecraft 1.21.1 on NeoForge.

## What's included

- FE-powered Adaptive Controller with 1x1, 2x1, and 2x2 drawer faces.
- Balanced, Proportional, and Manual layouts, with several sorting options and six priority directions.
- Manual cell locking, offhand item assignment, empty-cell reservations, and pinned drawer sizes.
- Searchable storage and crafting grids.
- Adaptive Deposit, Extender, Armory Drawer, and Fluid Drawer.
- Automatic connections for nearby blocks, plus manual connections with Functional Storage's Linking Tool.
- Safeguards for breaking controllers and drawers that still contain items.
- Up to 2,147,483,647 stored items per item type.

## Required dependency

- Functional Storage 1.5.5 or newer.

## Before installing

This is the first public release. Back up important worlds before adding a new mod. If you find a bug, include the game log and a description of your drawer setup when reporting it.
