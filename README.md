# Adaptive Functional Storage

Adaptive Functional Storage is a NeoForge 1.21.1 addon for Functional Storage. It turns a wall of drawers into one shared, FE-powered storage network. As the contents change, each drawer can switch between 1x1, 2x1, and 2x2 faces.

The default Balanced layout spreads items across the available drawers. Proportional layout gives more room to the items you have the most of, while Manual layout lets you choose drawer sizes and pin items to specific cells. The mod also includes storage and crafting grids, a deposit block, extenders, armory storage, fluid storage, and support for Functional Storage's Linking Tool.

## Requirements

- Minecraft 1.21.1
- NeoForge 21.1.x
- Functional Storage 1.5.5 or newer
