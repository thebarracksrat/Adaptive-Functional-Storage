# Adaptive Functional Storage

Adaptive Functional Storage is a Forge 1.20.1 addon that adds an FE-powered adaptive layer to Functional Storage. Link an Adaptive Matrix to a Functional Storage Controller and its Adaptive Drawers become part of the same network as ordinary Functional Storage drawers.

Adaptive Drawers retain the wood casing of their Functional Storage source drawer while using animated digital faces that can reorganize between 1x1, 2x1, and 2x2 layouts. Storage and Crafting Grids access the combined network, while the Deposit Port provides a direct insertion point. Adaptive variants are available for the vanilla wood families, crimson, and warped drawers.

The Adaptive Matrix consumes 20 FE/t plus 5 FE/t for every linked, loaded Adaptive Drawer. Storage remains intact when power is lost, but adaptive access and displays remain offline until power returns.

## Requirements

- Minecraft 1.20.1
- Forge 47 or newer
- Functional Storage 1.2.x (build target 1.2.14) and Titanium
